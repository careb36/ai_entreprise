# Informes de estado

Un archivo por informe, con fecha `AAAA-MM-DD.md`. Están escritos para
dirección: 1-2 páginas con el estado de los cinco sistemas y un anexo con la
evidencia que sostiene cada dato.

Para pedir uno, ejecutá el workflow **Informe de estado** (Actions → Run
workflow) o agregá la etiqueta `informe` a un issue. La fábrica abre un PR con
el informe y comenta el resumen ejecutivo en el issue de origen.
