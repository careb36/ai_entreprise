Added

* **A person can edit a task's title and description (issue #766).** A task the agents could not finish could only be sent back with a note: its text, which the Developer, the acceptance and QA read, stayed as the PO wrote it, so narrowing an over-broad task meant planning a new sprint. `PUT /v1/backlog/{id}/content` (Manager) changes the title or description, with a reason, while the task is in To do or Blocked (409 while an agent or the reviewer uses it, or once done). The change is the task's `edited` event, chained with its other events, with both texts before and after, the description's sha256 each side and the reason; it is audited as `backlog_item_edited`. `send_back` also sends the task back to work, so its rework budget starts again with the new text. The task details page has "Edit task" for Managers (`services/loop/task_edit.py`, `components/TaskEditForm.tsx`).
