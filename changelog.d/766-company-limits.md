Added

* **A company sets its own limits on its agents' work (issue #766).** An Owner sets, on the Models page or with `PUT /v1/companies/{id}/limits`, the Developer's tool rounds, how much of a tool's result it sees, the cap on its answer and a task's rework budget, each optional and within a range the code holds (1–50 rounds, 0–10 reworks...); an empty value keeps the deployment's, shown beside it. The company's value wins over `MODEL_PROFILES` and the run's evidence names it as the source; QA, the delivery gate and the quality gate read the company's rework budget. Each change is audited as `company_limits_changed`; a Manager and the agents cannot change them. Migration `0061` adds `companies.limits` (`null`, the deployment's values, for every company). `MAX_REWORKS` is a setting now.
