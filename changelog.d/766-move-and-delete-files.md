Added

* **A Developer can move lines between files and delete a file it emptied.** Two tools beside `workspace__edit`: `workspace__move` carries lines, byte for byte, from one file to another (created when missing), both files or neither and both still parsing, with the moved bytes' sha256 computed by the daemon; `workspace__delete` removes a file only once nothing is left in it, so code cannot vanish through it. A deletion is delivered as a `delete` entry the daemon applies only while the file still holds the bytes it reported, committed on the task's branch, undone by the snapshot, recorded on the evidence (`tool_edit_deletions`, status `deleted`) and counted as a change of a protected path. The backend offers the tools only when every daemon announces them (PROTOCOL.md §5.1.4). In sprint 6 (2026-11-23) a Developer could split a 642-line test file only by retyping it, wrote tests that called functions that do not exist, and could not remove the original. Design and threat model: `docs/design/move-and-delete-files.md`.
