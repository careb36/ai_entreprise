Fixed

* **A task's first attempt gets the write tools under the Git workflow (issue #766).** The task's worktree (`fabrique/task-<id>`) used to appear only at its first delivery, so a first attempt ran its tools in the person's checkout and was never offered `workspace__edit`, `workspace__move` or `workspace__delete`. The worker now asks the daemon for the worktree before the first turn (`workspace.console.prepare` with the new `private_git: false`, announced as a feature; PROTOCOL.md §5.1.5), and every tool of the attempt runs there; the person's checkout is never written and the delivery commits in the same worktree. The daemon's reply goes on the evidence as `tools_offered.task_worktree`. With a daemon that does not announce the feature, nothing changes. Design: `docs/design/first-attempt-in-task-worktree.md`.
