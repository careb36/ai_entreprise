Changed

* **A sprint that settles with nothing done pauses instead of completing (issue #766).** Sprint 7 closed as `completed` with all four tasks blocked. Now a sprint whose tasks are all settled, with none done and at least one blocked, pauses with the reason on the sprint, and a person resumes it once the blocked tasks are unblocked, done or discarded. A sprint with any task done still completes around its blocked tasks.
