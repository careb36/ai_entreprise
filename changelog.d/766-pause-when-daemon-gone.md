Fixed

* **No agent turn runs blind when the workspace daemon is gone (issue #766).** On sprint 6 the daemon had died; a QA task ran anyway, every workspace tool call failed with "no responders", QA delivered a report without reading a file and the review spent a rework sending it back. Now, before claiming a task, when no daemon heartbeat was heard within `DAEMON_HEARTBEAT_OFFLINE_SECONDS` and NATS answers "no responders", the worker pauses the sprint with the reason, keeps the task `todo` without counting a rework, records a `sprint_daemon_absent` audit incident and says on the Glassroom to run `./scripts/start-daemon.sh` and resume. A run whose workspace tool calls were all answered "no responders" (now marked `daemon_absent` on each call's observation) is discarded the same way instead of going to review. A timeout is not taken for an absent daemon.
