* **The backend's configuration is in one place (issue #766).** Fifteen operational values that modules read with `os.getenv` (the dispatch cooldown, QA's automatic rework, integration retries and concurrency, the proxy client's retries, the CLI cooldown and the workspace snapshot's caps) are settings in `config.py`, documented in `docs/CONFIGURATION.md` and reached by `.env`; every module reads `LLM_PROXY_URL`, `POSTGRES_*`, `NEO4J_*` and `NATS_URL` from `settings`, where about twenty call sites read them again with two different proxy defaults. `scripts/check_config.py`, after AixleHQ/flow's `NoEnvInApp` rule, keeps it so: only `config.py` reads the environment, the files that still do are listed with a reason and may only shrink, and every setting must be documented.
